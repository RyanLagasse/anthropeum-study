Anthropeum Study · UI direction

Museum Label

White walls, black type, a strict grid. The only saturated colour on any screen is data: twenty era colours and fourteen region colours. One orange-red accent marks the primary action. Seven frames follow, built with the real map engine and the real data files.

01Shell + DeskSlim text navigation along the top. The Desk opens on one era: its dates as the headline, the period borders beside it, the twenty-era bar as the footer rule.
02AtlasGrey land, white borders, region-coloured bubbles. The ranked list repeats the same colours, so the map and the table read as one figure.
03TellsCards set like wall labels: a bold title, a short description, hairline rules. A covered answer is a flat grey panel, not a blur.
04WhenA plain chart. Grey bars start at each first appearance; coloured ticks are arrivals by region. The selected rule is set at headline size.
05ScriptsSpecimen sheets. Each script is shown large in its own typeface on white, with dates and an era strip underneath.
06aPractice · questionThe object gets the left half of the screen, like a work on a wall. Map and era picker are numbered steps on the right; one accent button.
06bPractice · reveal and calibrationThe score is the largest thing on the page. Guess is black, answer is the accent. The label for the object appears only now. Calibration tiles sit below.
07Design notesPalette, type, data colours and trade-offs.
